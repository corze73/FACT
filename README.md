# FACT – Find A Coach Today (PWA)

FACT is a full-stack Progressive Web App that connects users with sports, fitness, and life coaches. 
It includes authentication, role-based dashboards, booking workflows, calendars, profiles, reviews, 
and coach availability management.

## 🌐 Live App
https://findacoachtoday.com

## 🧰 Tech Stack
- React (Expo Web)
- TypeScript / JavaScript
- Neon (PostgreSQL)
- Netlify (Frontend + Serverless Functions)
- Tailwind CSS
- Authentication using email/password
- Cloud storage for profile images

## 🏗 Features
- User + Coach signup and login workflow
- Role-based dashboard routing (user, coach, admin)
- Coach availability system
- Booking flow (Select coach → Pick time → Confirm)
- User and coach profile editing
- Messaging system (in-progress)
- Calendar UI for bookings
- Review & Ratings system (in-progress)
- Admin dashboard: coaches, reports, settings

## 🗄 Database (Neon)
- Structured PostgreSQL schema for users, profiles, bookings, reviews, availability and messaging  
- Policies and role logic handled via app-level API functions  
- Optimised for scalability and future AI integrations

## 🚀 Getting Started
npm install  
npm run web
